# Перенос базы на Aiven

Текущая рабочая база задаётся в `.env` переменной `DATABASE_URL`.

## 1. Создать Aiven PostgreSQL

1. Откройте https://console.aiven.io/
2. Создайте сервис `PostgreSQL`.
3. Выберите план `Free`.
4. После создания скопируйте `Service URI` / `DATABASE_URL`.

## 2. Перенести данные

Запустите:

```bash
./MIGRATE_TO_AIVEN.command
```

Скрипт:

- читает текущую Render-базу из `.env`;
- создаёт локальный backup в `backups/`;
- создаёт таблицы в Aiven;
- переносит пользователей, месяцы, операции, цели и служебные request id;
- не меняет `.env` автоматически.

## 3. Переключить бота

После успешной проверки Aiven замените в `.env` строку `DATABASE_URL=...` на Aiven `DATABASE_URL`.

Потом запустите:

```bash
./START.command
```

## 4. Не удалять Render сразу

Render-базу лучше оставить на несколько дней как страховку. Удалять её можно только после проверки, что бот пишет новые операции в Aiven.
