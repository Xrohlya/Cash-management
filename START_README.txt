Быстрый запуск в Visual Studio Code

1. Откройте папку 01-CashManagement в VS Code.
2. Скопируйте .env.example в .env и заполните параметры.
3. Остановите старую копию бота с тем же токеном.
4. Нажмите Cmd+Shift+B.

Также можно выбрать Terminal -> Run Task -> Cash Management: запустить
или дважды нажать START.command в Finder.

Локальный API: http://127.0.0.1:8788/health
Для Telegram Mini App задайте публичный HTTPS-адрес в WEBAPP_URL.
Подробности: README.md и CLOUD_DEPLOY.md.
