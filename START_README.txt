Быстрый запуск

1. Скопируйте .env.example в .env.
2. Заполните BOT_TOKEN.
3. Остановите старую копию бота с тем же токеном.
4. Запустите START.command.

Локальный API: http://127.0.0.1:8788/health
Для Telegram Mini App задайте публичный HTTPS-адрес в WEBAPP_URL.
Подробности: README.md и CLOUD_DEPLOY.md.
